# Travel History

Private, self-hosted catalog of a family's lifetime of travel: Google Timeline imports, live
tracking (OwnTracks/Overland), flights, routes, vehicles, statistics and optional public trip
pages. Django + PostGIS + React/MapLibre, all in Docker.

- Design, phases and decisions: [PLAN.md](PLAN.md)
- Working rules for contributors and AI sessions: [CLAUDE.md](CLAUDE.md)

This repository contains no personal data; tests use synthetic fixtures only.
